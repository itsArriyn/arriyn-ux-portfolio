02 / Game UI / Interaction Design

Blue Lock FC.

A football game menu concept inspired by the Blue Lock anime, combining familiar navigation with character-driven visuals and interactive menu descriptions.

RoleUX/UI Designer
ToolsFigma
ProjectGame Menu Concept
The Challenge

Making menus feel like part of the game.

My goal was to create a football game menu that was easy to understand while capturing the energy and competitive atmosphere of Blue Lock.

The design focuses on clear menu options, character visuals, and descriptions that explain what each mode offers.

01 / Research

Looking at existing football games.

I explored the menu experiences of EA Sports FC 24 and eFootball to compare navigation, visual hierarchy, and how different game modes are presented.

EA Sports FC 24

A reference point for organizing different football game modes and menu navigation.

eFootball

A second reference for understanding how football games present their primary options.

02 / Define

Designing for the player.

I developed a player persona to help consider gaming preferences, familiarity with controllers, and expectations when navigating a football game menu.

03 / User Flow

Mapping the menu experience.

The menu includes KickOff, My Team, Online, and Settings. Selecting an option reveals a description and changes the visual presentation before the player enters the chosen mode.

05 / Final UI

The Blue Lock FC experience.

The final concept uses Blue Lock character artwork, bold typography, and a blue-accented menu. Each selected mode displays a description to help players understand their options.

06 / Usability Testing

Testing the navigation.

I tested the menu concept with three participants, asking them to identify screens and explain how they would access different features.

Finding a game mode

Participants were asked how they would start playing a match.

Playing online

Participants were asked how they would access online play with friends.

Changing controls

Participants were asked how they would change the button assigned to passing.

Understanding the interface

Participants were asked to identify the screen and interpret the available navigation options.

The responses helped me evaluate whether the menu labels and navigation were understandable to players.

08 / Reflection

What I learned.

This project gave me experience designing a game interface that balances visual personality with clear navigation. It also reinforced the importance of testing whether users understand menu labels and can find the features they need.
