02 / Game UI / Interaction Design

Blue Lock FC.

A football game menu concept inspired by the Blue Lock anime, combining intuitive navigation with character-driven visuals and interactive menu descriptions.

Role UX/UI Designer
Tools Figma · Adobe Photoshop
Project Game Menu Concept
The Challenge

Making menus feel like part of the game.

My goal was to create a football game menu that was easy to understand while capturing the energy and competitive atmosphere of Blue Lock.

The design focuses on recognizable menu options, character visuals, and descriptions that help players understand what each game mode offers.

01 / Research

Exploring football game interfaces.

I explored existing football game interfaces, including EA Sports FC 24 and eFootball, to consider menu navigation, visual hierarchy, and how game modes are presented.

EA Sports FC 24

A reference for organizing football game modes and navigation.

eFootball

A reference for how football games present their primary menu options.

02 / Define

Designing for the player.

I developed a player persona to consider gaming preferences, navigation expectations, and how players interact with football game menus.

03 / User Flow

Mapping the menu experience.

The interface features four main options: KickOff, My Team, Online, and Settings. The user flow explores how players navigate through the menu experience.

04 / Wireframing

From structure to visual design.

Before creating the final interface, I explored different menu layouts through low-fidelity wireframes. These helped me experiment with button placement, navigation hierarchy, and selected-mode descriptions.

Low-Fidelity Wireframes

05 / Final UI

The Blue Lock FC experience.

The high-fidelity designs bring the Blue Lock FC concept to life through bold typography, anime-inspired visuals, and interactive menu elements.

One of the key features of my design is the integration of animated scenes from the Blue Lock anime within the menu selection boxes. Each game mode (KickOff, My Team, Online, and Settings) features anime visuals intended to create a more dynamic and engaging experience.

Rather than relying on static menu elements, I wanted the interface to feel alive while maintaining clear navigation and usability. This approach combines the excitement and visual identity of Blue Lock with the familiar structure of a football video game menu.

06 / Usability Testing

Testing the navigation.

I used navigation tasks to evaluate whether players could understand the menu options and locate different features.

Starting a match

How would a player begin a football match?

Playing online

How would a player access online play with friends?

Changing controls

How would a player change the button assigned to passing?

Understanding the interface

Can players recognize the menu and interpret its available options?

These tasks helped assess the clarity of the menu labels and overall navigation.

08 / Reflection

What I learned.

This project allowed me to explore how visual identity and usability work together in game interface design. I practiced developing different menu layouts, building a high-fidelity interface, and considering how users navigate between game modes.
